# Unterlagen

Hier kommen Zuarbeiten hinein: Marktpläne als PDF, Wanzl-Workbooks,
Regallisten, Fotos von Bestandsmärkten.

**Der Inhalt dieses Ordners wird nicht auf GitHub hochgeladen.** Das
Repository ist öffentlich, diese Unterlagen sind es nicht. Dafür sorgt der
Eintrag `unterlagen/*` in der Datei `.gitignore` – nur diese LIESMICH-Datei
selbst ist ausgenommen, damit der Ordner im Projekt sichtbar bleibt.

Leg die Dateien einfach hier ab. Eine Ordnung darin ist nicht nötig, aber
hilfreich sind sprechende Namen, zum Beispiel:

```
unterlagen/
├── Marktplan-Immenhausen-2025-03-26.pdf
├── Workbook-Trockensortiment.pdf
├── Workbook-Obst-und-Gemuese.pdf
└── Workbook-Bake-Off.pdf
```

Achtung beim Abgleich: Auch die Synchronisation über Cloudflare überträgt
diese Dateien nicht – sie kennt nur Marktplanungen. Auf einem zweiten Rechner
sind die Unterlagen also nicht automatisch da.
